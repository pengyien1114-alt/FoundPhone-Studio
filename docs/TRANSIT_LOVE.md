# 換乘戀愛：第一階段

故事來源為 `stories/template/story.json`。原手機鎖屏、桌面、49 個 App 與操作方式保留。密碼為 **0112**。

遊玩順序：備忘錄「01｜入住前的秘密備忘錄」→ X 第一天 → Safari 的 theqoo → KakaoTalk「合宿節目組」。動作點訊息泡泡觸發選項；話語點下方「输入消息」欄選擇預設台詞。三次互動後，可先閱讀各 App 更新與備忘錄心意紀錄，再點「結束第一天」。結束畫面可重新開始。

初始設定選七位男嘉賓中的六位、其中一位前任 X、是否後期登場、分手原因與復合傾向；換乘為互補百分比。女嘉賓是玩家與尹書妍、韓知恩、宋夏琳、崔有真、白恩彩。其餘五位男嘉賓依選擇順序與五位女嘉賓配對，私密名單與固定人物資料保存在備忘錄。首日固定五男五女，中期再加入一男一女鯰魚，完整陣容六男六女。指定 X 為鯰魚時男鯰魚固定為 X；未指定時從其餘五男抽一位。女鯰魚從五位固定女嘉賓抽選，玩家始終首日入住。抽選結果與本輪設定一起保存；寄給 X 的心意交節目組保管。未選的第七位不會進入劇情。全員無照片，男嘉賓選擇僅呈現姓名。所有戀愛經歷均為虛構。

三次選擇（晚餐、讀信、匿名心意）各有三種方向，共 27 條第一天路徑。復合變化依序為 ±15、±10、±20（或 0），總值限制於 0–100，換乘始終等於 100 減復合。theqoo 是遊戲內模擬，觀眾只評論鏡頭呈現的表現，不讀取分手原因、前任名單或匿名訊息全文。

必要的既有程式擴充：原備忘錄詳情可根據 `meta.profileForm` 顯示設定表單；資料保存在既有 Runtime.ui / IndexedDB。一般備忘錄不受影響。文字中的 `{{player}}` 等欄位經純文字替換，使用原 React 呈現，不執行 HTML 或腳本。事件、內容解鎖與選項仍使用原引擎。

## 第一天文字直播更新（revision 4）

X 預先提供八則虛構日常動態與官方預告。設定完成後，首次開啟 X 會沿用原推文詳情彈出「換乘戀愛官方」的置頂直播；每次 KKT 選擇後，回到 X 都會出現下一段官方推文。最新一段置頂，已讀段落保留。閱讀當前官方劇情後才開放 KKT 的下一個提問，避免略過劇情連續作決定。

分手理由改為六種一句摘要，完整背景資料仍放在故事 JSON 的 `setup.meta.backstory0` 至 `backstory5`。入住心緒、介紹信、三種互動方向與給 X 的訊息依玩家所選背景及當日選擇呈現；後期鯰魚只透過預先留下的信出現，不會被寫成已經入住。第五種背景保留童年約定與沒有告白的模糊關係；節目當下雙方都已成年，是否戀愛由雙方明確選擇。背景中的私密細節不會直接複製到 theqoo。

此修訂會使用新的存檔版本，首次更新後需重新完成入住設定。


## 陣容與集數討論更新（revision 5）

新增的鯰魚人選保存在設定的 `maleCatfish` 與 `femaleCatfish`；每輪只抽一次，不因開關 App 或刷新而重新抽選。首日的男搭檔與四位女嘉賓只從已入住者選用。三個決策切點保留，補長玄關、破冰、晚餐、洗杯子、讀信後相處及睡前段落。每則 X 推文均預生成六則留言。

KKT 原介面保留，`meta.selectionMode` 分為 action 與 speech。action 從訊息泡泡觸發；speech 從唯讀輸入欄開啟固定台詞選單，選擇後顯示成已發送的訊息。非故事模式的原聊天功能不受影響。

theqoo 依 EP.1／EP.2 分集。EP.1 是同一個持續更新的討論串：入住時 30 樓，每次選擇依實際路線追加 10 樓，第一天結束共 60 樓。未選分支及未到達的階段不會顯示；EP.2 目前為待播提示，後續劇情尚未製作。更新至此版需重新設定角色。
